# Phase 4: llms.txt generation and drift test

## Overview
Serve `/llms.txt` (index, llmstxt.org format) and `/llms-full.txt` (concatenated frontend contract) from the CMS host so any agent given only the CMS URL finds the contract.

## Requirements
- Functional:
  - `/llms.txt`: H1 `KDIGI CMS`, blockquote summary (headless, REST anonymous reads, MCP for editors), sections with links: Frontend contract (GitHub URLs of `docs/rest-api.md`, `docs/seo.md`, `docs/multi-site.md`, `docs/frontend-with-ai.md`), Agent skills (`skills/kcms-frontend`, `skills/kcms`), Optional (`docs/ai-integration.md`), plus `/llms-full.txt`.
  - `/llms-full.txt`: `skills/kcms-frontend/SKILL.md` + `references/contract.md` + `docs/rest-api.md` + `docs/seo.md` (frontend-relevant), each prefixed with a source header.
  - Static, instance-agnostic (no per-site data; that is `KCMS.md`).
- Non-functional: generated by `pnpm generate:llms`; files committed in `public/`; `pnpm test` fails with an actionable message when committed files differ from generator output.

## Architecture
- `src/scripts/generate-llms.ts`: `buildLlms(readFile) → { index, full }` pure; CLI entry writes `public/llms.txt`, `public/llms-full.txt`.
- `src/scripts/generate-llms.test.ts`: compare committed files to `buildLlms(fs.readFileSync)` output; message `run pnpm generate:llms`.
- `package.json`: `"generate:llms": "node --import tsx src/scripts/generate-llms.ts"`.
- Served by Next static `public/` (no middleware exists; Payload owns `/admin`, `/api`). Docker `runner` copies `public/` → available in images.
- GitHub base URL from `package.json` `repository.url` (no hardcoded duplicate).

## Related Code Files
- Create: `src/scripts/generate-llms.ts`, `src/scripts/generate-llms.test.ts`, `public/llms.txt`, `public/llms-full.txt`
- Modify: `package.json` (script)

## Implementation Steps
1. Implement pure builder; strip YAML frontmatter from SKILL.md in full output; normalise relative links to GitHub URLs.
2. Generate, commit outputs.
3. Drift test.
4. `pnpm dev` → `curl -i localhost:3000/llms.txt` and `/llms-full.txt` → 200, `text/plain`.

## Success Criteria
- [x] Both URLs 200 on dev server.
- [x] Editing `docs/rest-api.md` without regenerating fails `pnpm test` (verify once by local edit, then revert).
- [x] Full file size reasonable (< ~150 KB); no secrets/real domains.

## Risk Assessment
- Test brittleness on line endings → normalise `\r\n`.
- `seo.md` contains admin-only sections → include whole file but mark source; acceptable, or slice by headings if > size budget.
